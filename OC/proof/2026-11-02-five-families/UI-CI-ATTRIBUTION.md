# UI performance check attribution

The CI performance gates are still red; this report does not waive them. CI uses a fixed build identity. Its Chat base is already over the absolute cap at 1,278,335 B gzip. The custom-model draft candidate reports 1,278,429 B (+94 B), and the English-label candidate 1,278,468 B (+133 B); the allowed variance is 64 B, so they exceed the effective limit by 30 B and 69 B. The CI artifact outputs were not normalized or reproduced byte-for-byte locally.

A separate local three-way build used Node 26.12.1, Vite 8.3.5, Pako 3.0.2, the repository comparison environment (fixed branch/commit/time/build ID and Git disabled), and unchanged prepared plugin assets. Source baseline b0fdadd6b3448af5e23c45794465d48d97944fbe, draft head 34c8b5f087811d7bb18d51d58e7a35beeb036e5d, label head 89693e8cbea4cf4ef7daa77386b56f65203f3cf8. The normal Vite source builds were followed by `node --import ./scripts/tsx.mjs scripts/check-control-ui-performance.mts --json --report-only --module-attribution`.

All three local Chat boot graphs contain 20 JavaScript assets and 4,092,487 raw bytes. Aligning asset names by stable stem and replacing only the trailing eight-character emitted filename hash makes all 20 JavaScript bodies byte-identical in each comparison. Source-map module names and attributed raw byte counts also match. Local gzip totals differ (baseline 1,277,765 B; draft 1,278,121 B; label 1,278,136 B) despite the identical normalized program text. `compare-ui-boot.mjs` records the precise normalization and per-asset source hashes/metrics. This establishes a local filename-hash compression effect; it does not turn the CI gate green or prove that the CI artifacts have the exact same cause.

No budget, compressor, boot grouping, source logic, or CI assertion was changed for this attribution. The target repairs remain two existing-owner edits backed by paired browser proof. The current CI blocker needs the normal performance-policy decision or a separately justified owner change; it is not addressed by arbitrary hash-changing source edits.
